# 先做一刻 · FirstStep

<p align="center"><img src="assets/AppIcon.png" width="128" alt="先做一刻图标"></p>

本地运行的 macOS 专注工具：任务收集箱、悬浮番茄钟、习惯养成与定时提醒、每日专注森林与周月统计、Chrome 分心网站屏蔽，每天 07:00–20:00 的手动时间记录，以及可选的 AI 任务拆解、每日复盘和自由对话。MIT 开源。

Mac 自用的轻量专注工具：写下今天的核心任务，选 15 / 25 / 30 / 45 分钟开始。右上角悬浮小窗显示当前任务与倒计时；Chrome 扩展暂时屏蔽你设置的网站，初始包含雪球、X、微博。

## 首次使用

下载或克隆本仓库后安装。需要 macOS 13+、Swift Command Line Tools、Python 3；测试额外需要 Node.js 18+。当前在 Apple Silicon Mac 上验证，Intel 尚未实机验证。

```sh
xcode-select --install
python3 --version
```

如果已安装 Command Line Tools，可跳过第一条。

升级前先结束专注并退出旧应用。安装程序会更新本地主机并让已连接的扩展自动重连，保留已有记录。应用 0.11.0 继续使用扩展 0.2.0，无需再次授权网站权限。

1. 双击本目录的 `安装.command`。应用安装到 `~/Applications/先做一刻.app`，随后自动打开。
2. 按 [安装说明](安装说明.md) 在自己的 Chrome 中加载本地扩展。已安装并连接的用户可以跳过。
3. 应用显示「Chrome 已连接」后，添加任务、选中任务，点击开始。扩展未连接时只能计时，界面会明确提示。

扩展目录：`~/Library/Application Support/FirstStep/ChromeExtension`。
Chrome 中打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」。文件选择框按 ⌘⇧G，输入上面的完整路径并选择该文件夹。Chrome 不必关闭；我们不接管你的浏览器。

无痕窗口需要在扩展详情中单独允许；其他 Chrome 用户配置需要分别加载。其他浏览器不在本版本的限制范围内。

从旧版升级到应用 0.3.0 / 扩展 0.2.0 后，请在 `chrome://extensions` 重新加载扩展，确认新增的网站权限；在扩展详情中允许访问所有网站。应用会检测旧扩展和权限缺失，未就绪时明确提示仅计时。

## 使用约定

- 默认 15 分钟，下一步可不填。任务保留，未完成的任务次日仍可继续。
- 开始后，已经打开的相关网站也会进入拦截页；结束后恢复原网址。
- 临时访问：点击临时访问 → 可选填写原因 → 开始等待 30 秒 → 再次确认后，单站开放 5 分钟。不会自动放行。
- 提前结束和正常退出：先等待 30 秒，再确认。关闭主窗口不会结束计时。
- 浮窗可以拖动；菜单栏的倒计时可以重新打开主窗口。不会强制自动开始下一轮。
- 计时记录保存在本机；只有手动发起 AI 对话时才发送本次所需内容。临时放行时段从记录的专注时间中扣除；这表示可用时段，不监视你是否实际浏览。
- 主动停用扩展仍能绕过。扩展断连时按已知截止时间解除；电脑休眠期间不会唤醒电脑，恢复后重新核对时间。

悬浮计时窗采用 112×112 点圆角小方块：任务名、倒计时、紫色进度条保持可见。鼠标移入后显示打开主窗口和结束按钮；长任务名截短显示，停留可查看完整任务与下一步。提前结束仍需等待确认。断开 Chrome 时显示橙色提示和「仅计时 · 未连接」。

## 每日计划、任务安排与周复盘（0.12.0）

「今天的事」点击「安排今天」，查看到期的收集箱事项、之前未完成的任务和已安排到以后的事项。可选择加入今天、修改安排或留待以后；加入只选中任务，不会启动专注。未来安排的已有任务在到期前不显示在今天，到期后仍可调整；原来未设置计划日期的未完成任务保持显示。

在收集箱或任务的更多菜单选择「安排日期或提醒」。可选本机提醒时间；应用运行时在右上角显示，专注期间延后，支持加入今天、稍后 10 分钟或关闭。退出应用或休眠期间不会唤醒电脑，重新打开或唤醒后可显示未处理的到期提醒。任务完成会清除提醒；移到今天时保留未处理的提醒，点击提醒上的「加入今天」后不重复提示。多个任务到点时显示待提醒数量并逐条处理。

「时间记录」新增可选关联任务，保留独立的记录标题和关联时的任务名称；任务卡片可以展开查看关联记录，删除或改名任务不会抹去历史记录。时间记录仍表示手动填写的事项，不自动生成或叠加番茄钟时长。

「AI 助手 → 每周复盘」可选周内日期，按周一至周日查看专注、完整番茄、完成快照和手动记录的数量。展开资料预览后，手动发起复盘才会发送本周相关任务、计划在该周或更早且目前未完成的任务、专注、已保存想法及时间记录和补充；不发送习惯与想法草稿。完成时间未知的旧记录不计入；当前任务状态不等于当时状态；完成快照显示截至完成时的历史累计投入，不能当成本周投入。资料超过限制时提示，不静默截断。

「专注记录」增加一天中的专注时段，可查看最近 7 天、4 周或 90 天。整轮净专注时长按开始小时归类，包含提前结束；它表示何时专注较多，不代表效率评分。

本版使用状态 schema 6、时间记录 schema 3（0.12.1 起）、AI 复盘文件 schema 2。升级后旧程序会拒绝写入这些新版本，不能直接用旧版回退；需要先恢复升级前的数据备份。

## 习惯养成（0.11.0）

在左侧「习惯养成」新增自己的习惯，设置名称、最小行动、可选行动时机，以及每天、工作日（周一至周五）或自选星期。提醒可自行开启并设置本机时间。首次打开不预置习惯或虚构记录。

点击卡片「今日已做到」，一次打卡立即选中该习惯、回到本月并给今天填色；再次点击可撤销。选择习惯名称查看它的自然月历，支持翻月、补记、可选实际量与修改记录。完成日绿色、计划内未完成留白，未来和创建前日期不能打卡，非执行日仍可自愿记录。暂停或修改规则保留历史，已有完成记录保留当时的最低行动。

应用保持运行时，到点在桌面右上角显示安静的小卡片，保留到选择完成、稍后10分钟或关闭。提醒不抢输入焦点；番茄钟期间顺延到本轮结束，已完成的习惯当天不再提醒。关闭主窗口后仍可提醒；退出应用或电脑休眠期间不唤醒电脑，重新打开/唤醒后核对当天未处理的到期提醒，不追补前一天。新建习惯当天的时间已过时，从下一个执行日开始提醒。习惯独立保存于本机 `habits.json`，不发送给 Chrome 或自动附入 AI。

## 快捷键与快速操作（0.8.1）

应用保持运行时，在其他软件中也能快速记事：

| 操作 | 默认快捷键 |
| --- | --- |
| 添加今日任务 | Control + Option + Command + N（⌃⌥⌘N） |
| 添加收集箱事项 | Control + Option + Command + I（⌃⌥⌘I） |
| 显示／隐藏主窗口 | Control + Option + Command + O（⌃⌥⌘O） |
| 开始当前选中的任务或小任务 | Control + Option + Command + S（⌃⌥⌘S） |
| 显示／隐藏悬浮计时窗 | Control + Option + Command + F（⌃⌥⌘F） |

弹出的输入框只需写标题；回车保存，Esc 取消，保存后返回原来的软件。不会自动启动番茄钟；正在专注时也能补记，当前任务和倒计时保持不变。主窗口关闭后仍可使用，退出应用后快捷键才停止生效。

开始专注沿用当前已选任务、小任务和时长。正在计时时重复按键不会重新开始；休息或等待确认时不会跳过原流程。无有效选择时会打开主窗口提示选择；快速输入、编辑或确认窗口打开时不后台启动。

主窗口快捷键只切换主窗口，悬浮窗可独立保留。悬浮窗在本轮隐藏后会保持隐藏，新一轮自动显示；没有专注或休息计时时，快捷键会打开主窗口，不显示空计时窗。

在左侧「设置」点击对应快捷键按钮，然后按下新的组合即可修改，也可停用或恢复默认。选择字母或数字，搭配 Command、Control、Option 中至少两个键，Shift 可选。系统注册冲突会明确提示，失败保留原设置；离开设置或按 Esc 会退出录制。快捷键只接收指定组合，不需要辅助功能或输入监控权限。

## 本轮想法与结束铃声（0.10.0）

正常完成或提前结束一轮后，会响一次2.5秒柔和短铃，并弹出可立即输入的「本轮想法」窗口。自由写下发现、困难或下一步，回车换行，⌘↩保存；可点「稍后再写」、Esc或关窗保留草稿。窗口会避开尚未关闭的任务编辑或快捷输入，不替换它们的内容。退出时也保存草稿，重启不会批量补弹或重放旧铃声。

在「专注记录」点击对应的树、树坑或记录，可查看、补写或修改本轮想法。想法绑定这一轮及当时的主任务/小任务，按该轮开始日期归档，跨日补写不挪到补写当天。每条最多8000字，已保存内容与未提交草稿分别保留。

保存只发生在本机，不自动调用AI。手动每日复盘附所选日期的已保存想法，自由对话附今日已保存想法，来源预览显示本次实际附上的文字；草稿、其他日期和不属于当前记录的内容不发送。云端上下文超限会提示并停止发送，不悄悄裁切，也不丢弃本机想法。

「设置 → 专注结束提醒」可开关铃声、试听一次。声音渐入渐出、不循环，音量跟随系统，不自动调整音量或静音。休息结束不触发本轮铃声或想法框。休眠期间不唤醒电脑，恢复后识别已结束轮次，最多提醒一次。

想法/草稿保存于本机 `focus-reflections.json`，铃声偏好位于 `completion-reminders.json`；与原业务状态分开，不发给Chrome扩展。原schema5、任务、森林、完成记录与五项快捷键保留。

## 完成记录与任务预估（0.9.0）

添加或修改今日任务时，可选填写预估需要的番茄钟数量。完整结束15/25/30/45分钟的任意一轮，都增加一个实心番茄；与预估相差的轮数显示为空心。提前结束只计实际净专注时间，不增加完整番茄。达到或超过预估都不会自动完成任务。

任务做完后手动标记完成，在左侧「专注记录」下面的「完成记录」回看：可按完成日期切换日、自然周（周一至周日）、自然月，搜索标题，分别查看完成主任务和小任务。每项显示完成前累计的番茄轮数与专注时长，包含此前日期的投入；主任务包含其小任务投入，页面总计按会话ID去重。

完成记录保存完成时的标题、预估和投入快照，恢复、删除或修改当前任务不会抹去它；再次完成会增加一次完成记录。仍存在的任务可以从记录菜单恢复到今天继续处理。旧版缺少准确完成时间的任务放在「日期未知」，不补猜日期，也不计入某日/周/月的完成数量。

「今天的事」保留未完成行动清单。收集箱和全局快速输入继续只需标题，可在任务编辑框补上预估。森林和柱状图仍按专注发生日期统计，与完成任务的累计投入分别展示。完成快照仅保存在本机，不发送给Chrome扩展。

## 收集箱

左侧点击「收集箱」，输入一个标题并按回车或点「收进来」，先暂存生活杂事和工作待办。只填写标题，最多 120 个字，不会自动排进今天，也不会启动番茄钟。

- 可以修改标题，删除后可点「撤销删除」。条目按新加入的在前显示，退出应用后仍会保留。
- 准备处理时点「移到今天」：从收集箱移出，在「今天的事」中选中该任务；之后自行选择时长并开始。
- 正在专注时也可以先记一件事、或把它排到今天，当前倒计时不会中断或自动切换任务。
- 定期回看，把准备做的事改写成一个能开始的动作。本功能采用 GTD 的收集和下一步行动思路，界面保留一张简单暂存清单。[GTD 官方流程](https://gettingthingsdone.com/what-is-gtd/)

## 屏蔽网站

左侧点击「屏蔽网站」，粘贴完整网址或域名，查看预览后点击「加入屏蔽」。例如 `https://www.bilibili.com/video/abc?from=home` 会保存为 `bilibili.com`，覆盖该域名及其子域。路径、参数和片段不会保存。

- 仅在番茄钟专注期间生效，结束后恢复访问；已经打开的匹配页面也会进入拦截页。
- 按输入域名屏蔽，不会自动扩大到上级域名：添加 `news.example.com` 不会屏蔽 `work.example.com`。常见的 `www.` 前缀会去掉。
- 初始包含雪球、X/Twitter、微博。可添加、移除，最多 100 组；同一网站与范围重叠的域名不能重复添加。
- 专注期间禁止增删列表；自定义网站也支持原有 30 秒等待后的单站 5 分钟临时访问。
- 列表为空时仅计时。只支持网站域名，不支持 IP、本机地址或 `chrome://` 等浏览器内部页面。

为方便以后只在 Mac 粘贴网址就加入屏蔽，扩展需要一次性获得 HTTP(S) 网站访问权限。程序只根据列表匹配页面地址，不读取网页正文，也不上传浏览记录；工作网站不会因为授予权限而进入屏蔽列表。

## 时间记录

左侧点击「时间记录」即可使用。默认显示周一至周日，可以切换单日，或通过日期控件、前后箭头和「今天」回看其他日期。

- 每天 07:00–20:00；点击空白或拖选时间段，填写事情、日期、起止时间、颜色和可选备注，再保存。
- 点击已有记录修改。拖动卡片移动时间；周视图可横向拖到另一日。拉动上下边缘调整起止，拖动按半小时对齐；手工填写支持分钟精度。
- 重叠记录并排显示。删除后可点击「撤销」。
- 完全手动填写，不会把番茄钟记录自动放入日历。

「时间记录」是全天活动的手动回顾；「专注记录」是番茄钟自动生成的明细。两者可以涵盖同一段时间，时长不应相加，也无需把每轮番茄钟重新抄入时间记录。左下角「今天已专注」只按番茄钟记录计算。

## 专注记录、每日森林与周月统计

左侧点击「专注记录」，查看当天完成的番茄钟数量、实际专注分钟和提前结束次数。每天独立一片森林，可通过周一至周日日期栏、前后箭头、「今天」和日期控件回看。

- 完整结束一轮种一棵树：15 分钟小树、25 分钟正常树、30 分钟稍大的树、45 分钟大树。提前结束留下树坑，不增加完成数量。
- 点击树、树坑或下方明细，查看对应任务、起止时间、实际专注分钟与临时访问次数。明细默认显示最新三条，可以展开全部。
- 按专注开始时的本地日期归档，跨午夜的轮次归开始当天。临时开放网站的时间扣除后计入专注分钟，树大小仍按原定时长显示。
- 已保存的旧记录自动生成森林，无需重新填写。本版起本地历史不再只保留最近 500 条；旧版已删除的更早记录无法补回。Chrome 只接收最多 500 条的状态快照，不会因此删除本地历史。
- 数据继续只保存在本机，未与手动「时间记录」合并，也没有新增 Chrome 权限。

切换页面右上角「日／周／月」查看不同范围：

- 「日」保留每日森林和明细；「周」按周一至周日显示每天的专注时长；「月」按每月 1 日至月底、以自然周分组显示时长。
- 周、月顶部只汇总总专注时长和完成番茄钟数量。月初、月末的部分周只计算当月日期；柱子显示具体日期范围。
- 指向或点击柱子，查看对应日期的时长和完成数量。用前后箭头、日期控件和「本周／本月」回看历史或返回当前。
- 时长沿用实际专注秒数，包含提前结束前的投入，扣除临时访问时段；完成数量只计算完整结束的轮次。按开始日期归档，旧记录自动统计，无需迁移。

## AI 助手与小任务

0.7.0 起新增左侧「AI 助手」，通过官方 Continue with ChatGPT 登录授权，使用账号允许共享的套餐额度，无需 API Key。可用模型由官方接口返回；套餐额度与其他接入应用共享，遇到限额时应用会提示。也可以不连接，所有原有功能和手动小任务照常使用。

- **任务拆解**：在 AI 页面选任务，或在任务菜单中点「AI 帮我拆解」。先回答 1–2 轮问题，再生成按 SMART 原则检查的建议。可以修改、移除草案，点击「采用这些小任务」后追加到原主任务，保留已有小任务；主任务已变化时不会强行覆盖。
- **选小任务专注**：在「今天的事」点击小任务文字选中，再选时长并开始。勾选框表示事情完成；番茄钟结束只记一轮，不会自动完成小任务或主任务。悬浮窗显示小任务，历史保留当时的主任务和小任务名称。
- **每日复盘**：手动选日期、查看将使用的记录，可以补充成果或困难。先问答，再生成事实、观察和可尝试的调整；同一天多次复盘都会保留。任务当前完成状态不等于当天完成，缺少完成时间的旧数据不会被当作当日产出。
- **自由对话（0.7.1）**：打开第三个标签即可自由提问并连续追问。默认附上当前本地日期的任务、小任务、手动时间记录及备注、净专注记录与汇总；未完成的旧任务也会附上，进行中的专注单独列出。发送前可以展开预览，历史问题可回看当时快照。每轮重新抓取今天，跨午夜使用新日期；只在手动发送时联网。
- **聊天历史**：完整问答保存到本机 `ai-chats.json`，可新建对话或打开历史。调用时附上当前快照、当前对话最近 5 轮完整问答和新问题；更早内容不会自动附上。问题最多 8000 字，日快照过长时明确拒绝并提示，不静默裁切。取消/网络失败保留草稿，可重试；保存失败仍展示完整回答并提供重新保存。
- **发送范围**：拆解只发送所选任务、已有小任务和本次回答；复盘只发送所选日期相关的任务、专注记录、手动时间记录及备注、补充和回答。自由对话使用前述今天的范围和最近 5 轮当前聊天。不会发送整个收集箱或其他 AI 对话，不会读取网页正文。手动记录和番茄钟可能重叠，不相加。
- **保存与退出**：完整建议及对话保存在本机 `ai-journal.json`，账号与模型偏好在 `ai-preferences.json`；授权文件位于 `AI/`（目录 0700、文件 0600）。退出会尝试撤销刷新凭证并清除本机令牌，保留注册信息，任务和复盘不删除。网络中断、取消或不完整回答不会加入任务。

官方接入说明（核查日期 2026-10-23）：[Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[模型与调用](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)、[预览限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。这是官方支持的套餐共享接入，账户是否可用及额度以授权页和应用实际返回为准。

## 数据和卸载

专注任务与记录：`~/Library/Application Support/FirstStep/state.json`；手动时间记录：同目录下的 `time-records.json`。退出应用后可复制此目录备份；其中 `AI/` 含登录凭证，备份应妥善保管，不要上传公开仓库。不要在专注进行中手动修改数据。

卸载：先结束专注；在 Chrome 删除「先做一刻 · 专注守护」扩展；退出并移除 `~/Applications/先做一刻.app`。本地主机配置位于 `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.dayuan.firststep.json`，可移除。个人记录默认保留在 FirstStep 目录，是否删除由你决定。
